# Protein Viewer

A single self-contained HTML page for viewing protein structures from the RCSB Protein Data Bank in different visual representations (cartoon, ribbon, tube, trace, stick, ball & stick, sphere, surface).

Enter any RCSB PDB ID (e.g. `1CRN`, `4HHB`, `6VXX`) and the structure loads directly from RCSB and renders in-browser using [NGL.js](https://nglviewer.org) — no build step, no server required.

## Usage

Open `index.html` directly in a browser, or serve it as a static site (e.g. GitHub Pages).
